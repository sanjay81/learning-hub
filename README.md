# Engineering Learning Hub

A single place for embedded-systems references and hands-on Git workflow exercises.

## Start here

- **[Embedded-systems resources](resources/embedded-systems/README.md):** collected notes and links on Linux boot, Raspberry Pi, Intel Edison/Brillo, board bring-up, and serial buses.
- **[Git workbook](courses/git-workbook/README.md):** small HTML and CSS snapshots used to practise branching, staging, merging, rebasing, cherry-picking, stashing, and related Git operations.

## Repository origins

This hub combines material from [IMPORTANT_LINKS](https://github.com/sanjay81/IMPORTANT_LINKS) and [DMAWorkbook](https://github.com/sanjay81/DMAWorkbook). It also consolidates the account's `github_acttion`, `work_2024`, and `devops` repositories. Those three repositories were checked and had no branches or tracked files, so there was no additional content to import. The `github_acttion` spelling is the actual GitHub repository name; no exact `github_action` repository exists under this account.

The original `IMPORTANT_LINKS` and `DMAWorkbook` repositories remain available for their earlier Git histories. `TestRepo` is not part of this hub and is being removed as requested.

## Keeping it useful

Many embedded-systems references were collected years ago. Check the publication date, current documentation, and hardware/software version before following a procedure. Link notes are references, not verified installation instructions. Add a short explanation and a last-checked date when refreshing a resource.
